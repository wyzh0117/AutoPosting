## Goal

Bottom of **热点候选** (`#hotspots-panel`) shows the titles that actually go into 生成文章: `pickedIdList()` chips when any pick exists; otherwise the focused card as muted `焦点`; otherwise hidden.

## Approach

- Inserted `<aside id="picked-dock" hidden>` as the last child of `#hotspots-panel` (after `#source-health-wrap`). In-flow flex row, `justify-content:flex-end`, wrapping chips — left panel 右下角, not a page overlay. Does not cover 生成文章 / 找切口 / 收藏.
- `body.lane-github #picked-dock, body.lane-skills #picked-dock { display:none !important; }` plus `#picked-dock[hidden]{display:none !important;}` so `display:flex` cannot leak the empty dock.
- `renderPickedDock()`:
  - Picks: `已选 N` + one chip per id. Title from `state.favoriteIds[id].title`, else scan `state.rankings.heat` / `time`. Chip click → `togglePicked(id)` (unpick). Chips `pointer-events:auto`.
  - No picks + `state.item`: one muted line labeled `焦点` (not counted as 多选; chip is a span, not a button).
  - Nothing: `hidden`.
- Call sites: end of `togglePicked`, `renderHotspots` (including empty list), `renderFavorites`. Guarded `if (typeof renderPickedDock === "function")`. Agent A already calls the same guard from `selectHotspot` / `clearHotspotSelection`; left those paths alone.

Did **not** change `selectHotspot` unfocus, `.hotspot-item.selected` gold-vs-bar CSS, `find_skills`, version, or 8080.
