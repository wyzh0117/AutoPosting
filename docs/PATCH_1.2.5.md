# AutoPosting 1.2.5

## 变更

1. 热点候选右下角已选框改为左对齐，条目增大字号、留白和最小高度，并最多显示两行；标题由内层元素负责裁切，避免按钮内边距区域露出第三行；文章编辑区保留自适应高度，同时锁定输入前后的页面滚动锚点。
2. 热点文章生成时将每个来源标记放在对应事实的首次引用位置，由安全的 `http(s)` 链接替换；同一来源的多篇原文使用 `source_id#2` 等唯一标记。来源清单、来源尾注和图片来源文字不再写入正文。
3. 到草稿时，已选正文图片包为指向原始页面的图片链接；微信正文保留安全 Markdown/HTML 超链接并转换为草稿 HTML。
4. 到草稿时从正文提取不超过 120 字的实质段落填入 `digest`，排除标题、来源、图片说明、讨论提示和 AIGC 声明。

## 边界

- 微信图文正文外链能否在最终群发后跳转仍受公众号认证和微信支付等平台权限影响；本地实现只负责生成安全链接，未进行真实账号群发。
- 摘要使用正文段落启发式选择，不新增模型调用；超过 120 字时截断。
- 本轮未改变文章类型或其他写作风格要求，只调整来源相关 prompt 规则；文章 prompt 版本升为 `article-v12` 以使旧缓存失效。
