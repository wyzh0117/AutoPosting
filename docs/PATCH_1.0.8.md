# AutoPosting 1.0.8

## 变更

- 工作台顶部增加全局等待条：开始即出现、显示已用时间、给出通常耗时，完成后明确说全部完成或失败。
- 长等待按钮从「处理中…」改为带秒数；抓取、翻译、找切口、生成文章、对话、原文、发布、导出、保存模型等都走同一套等待条。
- GitHub 周榜「生成图片」改为逐张调用 `/api/github-weekly/image`：画廊格子立刻进入排队/正在生成，进度写清第几张、哪一张、是否全部完成。配色随每张请求提交。

## 边界

- 全量 `/api/github-weekly/render` 仍保留给脚本；工作台界面不再一次卡到 11 张都结束。
- 小时切换、点选配图这类很快的本地操作不弹等待条。

## 验证

- unittest 279 通过。
- 离线 self-check 10/10。
- 服务 `/api/status` 版本 1.0.8。
- 浏览器：刷新全部时等待条显示「正在抓取订阅源 / 通常 10–30 秒 / 已用 Ns」，完成后「抓取完成」。GitHub 生成图片立刻出现「第 1 / 11 张 · 本周爆火ai工具」，格子「正在生成… / 排队中」，约 1 分钟后切到「第 2 / 11 张 · archify」。
