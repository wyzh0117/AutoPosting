# 第一阶段 MVP 计划

目标：用 Python 3.11 标准库、SQLite 和本地调度入口构建可离线验证的最小内容流水线。

1. 用测试固定 RSS 增量采集、URL/内容规范化、幂等去重和 SQLite 状态模型。
2. 实现透明且可配置的热点窗口规则，并用人工时间序列覆盖触发、拒绝和冷却分支。
3. 建立事实清单、公众号/小红书独立草稿、审批约束和仅生成本地发布包的适配器。
4. 增加 CLI、公开来源示例、离线自检、安装运行文档和架构决策记录。
5. 运行完整测试、自检、密钥扫描和项目目录边界检查，保存可复验输出。

阶段边界：不接入真实 LLM、X 私有接口、模拟登录或真实平台发布；没有明确授权与凭证时始终保持 dry-run。
