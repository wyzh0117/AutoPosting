# AutoPosting 0.4.3

## 变更

- “打开原文”不再只显示 RSS 入库字段：优先从候选的原站 URL 提取正文，过滤导航、脚本等页面噪声；原站不可访问时回退到 RSS 已收录内容并明确标注来源，临时失败不会被永久缓存。
- 原站抓取仅允许解析到公网地址的 HTTP(S) URL，重定向目标也执行同样校验，避免访问本机或私网地址。
- 原文弹窗新增“翻译文章”，英文原文保留在前，中文译文追加在后；切换候选或关闭弹窗时会丢弃过期响应。
- 设置页新增独立“翻译模型 / 用于翻译”入口。首页“翻译标题”和原文全文翻译统一使用该模型；模型用途可持久化、恢复和删除。
- 旧 SQLite 数据库会自动把模型用途约束从 `article/chat` 升级为 `article/chat/translation`，并保留已有选择。
- 翻译缓存加入模型接口地址作用域，避免两个接口使用同名模型时错误复用结果。
- 英文正文按正文语言占比识别，标题含“千问”等中文专名时仍可翻译；热点请求只允许最新响应更新列表，避免慢翻译覆盖新刷新结果。
- 设置中的三组模型用途统一栅格布局，窄屏自动单列；原文弹窗关闭按钮改为固定 36×36 圆形控件。

## 边界

- 付费墙、登录墙、反机器人或拒绝服务端访问的原站仍无法保证提取全文；此时显示 RSS 已收录内容和原站链接，不绕过站点访问限制。
- 全文翻译上限为 50,000 字符，沿用现有 OpenAI 兼容模型调用和 90 秒超时。
- 本次没有新增第三方运行时依赖，也没有改变发布安全规则。
