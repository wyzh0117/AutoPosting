# AutoPosting 1.0.19

## 变更

长任务不再锁死整个工作台。抓取、翻译、生成文章、找切口、周榜出图、导出、发布等都会在右上角弹出独立进度卡：说明正在做什么、大概要多久、已经过了几秒，并带「停止」。多张进度卡可以同时存在；切到别的栏不会取消进行中的任务。例如周榜正在抓取或出图时，可以切到「热点候选」再点「刷新全部」，两条进度并行。停止会中止浏览器侧请求，并跳过还没开始的后续张。

「GitHub AI项目周榜」拆成等宽标签「GitHub 周榜」和标题「GitHub AI 项目周榜」。周榜栏不再露出热点用的热度/时间排序和「打开原文」。仓库类型旁的「本周涨星」不再折成两行。

周榜出图左上角著作 id 改为「EE_萤飞」，并带上用户提供的头像。右上角期数不再写「本周」，改为 ISO 周年，例如今天是 `2026年第37周`。

## 边界

- 停止只取消本机前端的后续请求；已经打到模型/GitHub 的那一次调用仍可能在服务端跑完，结果不会再写回当前任务卡。
- 小红书仍是人工发布包。微信 live 行为未改。
- 示例 JSON（`docs/image_prompts/examples/`）仍用 AutoPosting 品牌，不影响周榜出图。
