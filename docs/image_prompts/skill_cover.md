# 任务类型

为一次 Skill 查找结果生成封面大字报。这是一组技能包的总封面，不是某一个仓库的详情卡。

画布必须是 3:4 竖图，推荐 1080×1440。不要 9:16，不要 1:1。

## 主题

标题：{title}
主题词：{theme}
技能数量：{count}
覆盖阶段：{stages}

## 文字层级

1. 顶栏小字：SKILL 查找器
2. 主标题：{title}（最大，居中，可折行）
3. 副题：{theme} · {count} 个技能
4. 底部阶段名：按「从左到右、从上到下、由浅入深」的顺序列出 {stages}，一行一个或两列短词

## 视觉

沿用本地大字报语言，不要科技紫、不要周榜靛蓝：

- 底：#3d2b1f
- 字：#ffffff
- 内框：10px 实心白框，距边缘约 60px
- 字体：Songti SC / STSong / SimSun / Noto Serif SC
- 主标题字重 700，字距略开
- 不要照片、不要仓库 logo、不要星标条、不要二维码
- 中文必须完整落在框内，禁止裁切

最终页面由 HTML/CSS 渲染后截 PNG，不把整页中文交给图像模型排字。
