# 任务类型

生成一张高完成度的科技信息视觉资产（主视觉、插画、3D 图标、抽象背景），不是整页中文海报。

最终含大量中文正文的页面由 HTML / CSS 渲染，不由图像模型排字。

目标不是宣传海报，而是制作一种兼具：
- 编辑设计感
- 数据可视化感
- 科技产品感
- 信息阅读效率
- 社交媒体传感器

的垂直信息图素材。

整体效果应类似：
“专业科技媒体 + AI产品官网 + 数据仪表盘 + 高端社交媒体信息卡片”。

画面必须首先保证信息层级清晰，其次才是装饰性。

----------------------------------------

## 画布

画面方向：竖版。

画面比例：9:16。

推荐尺寸：1080×1920（1k 高清）。

四周保留稳定安全边距。

所有元素必须完整位于画布内部，不允许：
- 文字越界
- 卡片被裁减
- Logo被截断
- 底部信息消失
- 边缘内容过于拥挤

## 整体视觉风格

视觉关键词：

Dark Technology
AI Native
Cyber Minimalism
Premium Dashboard
Editorial Infographic
Modern SaaS UI
High-end Tech Media

整体采用：
低饱和中性色为主体 + 高亮主题色 + 高对比正文 + 模块化卡片。

设计感觉：
高雅、专业、克制、现代、高级、干净、有科技感。

不要做成：
赛博朋克游戏海报、
霓虹灯海报、
电商促销海报、
传统ppt、
廉价渐变海报。

科技感主要来自：
- 排版
- 卡片
- 数据
- ui组件
- 微弱光效

而不是大量装修

## 颜色系统

采用颜色搭配黄金法则：主要颜色不要超过三种。60%主色、30%辅助色和10%强调色。

主色：低饱和度近黑中性色，决定空间基调。
辅助色：略亮的深色表面，支撑层次。
强调色：克制的紫晶色，只出现在排名、进度、关键数据。

整张海报最好避免彩虹式配色。
允许出现少量 glow 效果，但必须克制。

## 图标风格

简介、现代、线性或半填充式 ui 图标。

不同图标必须保持：
相同视觉重量、相同圆角语言、相近线宽。

尽量不要使用混合图标。

项目 logo 可以保持自身视觉特征，但放入统一的圆角图标容器中。

## 视觉一致性

如果生成一组系列素材：

必须保持：
相同背景、相同字体语言、相同颜色系统、相同卡片风格、相同边框、相同圆角、相同图标语言。

允许变化：
项目 Logo、主视觉、标题、数据、具体信息。

目标：任何单张拿出来，都能明显看出属于同一个视觉系列。

## 禁止事项

禁止大面积廉价渐变背景。
禁止过多霓虹灯。
禁止赛博朋克城市元素。
禁止复杂电路背景。
禁止粒子效果铺满画面。
禁止大量无意义光效。
禁止过多3D元素。
禁止卡通插画风。
禁止传统企业PPT风。
禁止电商促销风。
禁止文字拥挤。
禁止超小字号。
禁止随机乱码。
禁止不同模块使用完全不同设计语言。
禁止大量无意义装饰元素。
禁止让图像模型承担大量中文正文的最终渲染。

## 最终视觉要求

最终作品应给人这样的第一印象：

“这是一个专业AI科技媒体制作的内容卡片。”

而不是：

“这是AI随便生成的一张海报。”

视觉品质应接近：

高端AI SaaS产品官网
+
专业科技媒体
+
数据Dashboard
+
现代Editorial Design
