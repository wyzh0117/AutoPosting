# 任务类型

生成一张高完成度的“科技信息可视化海报 / 信息卡片”。

目标不是宣传海报，而是制作一种兼具：
- 编辑设计感
- 数据可视化感
- 科技产品感
- 信息阅读效率
- 社交媒体传感器

的垂直信息图。

整体效果应类似：
“专业科技媒体 + AI产品官网 + 数据仪表盘 + 高端社交媒体信息卡片”。

画面必须首先保证信息层级清晰，其次才是装饰性

----------------------------------------

## 画布

画面方向：竖版。

画面比例：9:16。

推荐尺寸：1k高清尺寸。

四周保留稳定安全边距。

所有元素必须完整位于画布内部，不允许：
- 文字越界
- 卡片被裁减
- Logo被截断
- 底部信息消失
- 边缘内容过于拥挤

## 整体视觉风格

视觉关键词：

Dark Technology
AI Native
Cyber Minimalism
Premium Dashboard
Editorial Infographic
Modern SaaS UI
High-end Tech Media

整体采用：
低饱和中性色为主体 + 高亮主题色 + 深色文字 + 模块化卡片。

设计感觉：
高雅、专业、克制、现代、高级、干净、有科技感。

不要做成：
赛博朋克游戏海报、
霓虹灯海报、
电商促销海报、
传统ppt、
廉价渐变海报。

科技感主要来自：
- 排版
- 卡片
- 数据
- ui组件
- 微弱光效

而不是大量装修

## 颜色系统

采用颜色搭配黄金法则：*主要*颜色不要超过三种。60%主色、30%辅助色和10%强调色

主色：决定整体空间的基调或轮廓，通常是低饱和度的中性色。
辅助色：支撑主色，丰富层次，与主色形成对比或和谐过渡。
强调色：用于打破沉闷，吸引眼球。内容产品中通常使用在用于强调的重要位置。

整张海报最好避免彩虹式配色。

允许出现少量glow效果，但必须克制。

## 版式系统

采用明确的纵向信息层级：

logo/品牌区域
↓
主题识别区域
↓
核心标题
↓
简介/副标题
↓
主题信息区域
↓
辅助信息模块
↓
来源 / 地址 / 页码 / 产品信息

整体遵循：

“大标题吸引注意” - “一句话快速理解” - “结构化信息辅助理解” - “细节信息支持进一步阅读”。

使用模块化网格布局。

优先采用：
- 左对齐
- 卡片式分区
- 清晰留白
- 稳定列宽

避免所有元素全部居中

## 文字风格

中文：
现代无衬线字体。

英文：
现代grotesk / geometric sans风格。

标题使用：
粗体 / heavy / bold。

正文使用：
regular / medium。

数字可以适当使用：
semibold / bold。

整体文字感觉接近：
现代科技公司官网、
AI产品UI、
高端数据报告。

## 图标风格

简介、现代、线性或半填充式ui图标。

不同图标必须保持：
相同视觉重量、相同圆角语言、相近线宽。

尽量不要使用混合图标。

项目logo可以保持自身视觉特征，但放入统一的圆角图标容器中。

## 页面类型

整个视觉系统主要生成cover和poster两种页面。

### cover
榜单总览页

页面结构：

01 超大主标题“GitHub”
02 副标题“本周爆火AI项目榜”
03 时间 / 期数
04 榜单详情
05 Top N项目排行榜
06 数据指标
07 底部主题标签

排行榜单项结构：

[排名]
[logo]
[名称]
[一句话介绍]
[数据指标]
[进度条]

### poster
页面结构

01 项目名称
02 排名 / 分类标签
03 项目名称
04 一句话定位
05 项目主视觉
06 核心介绍
07 一句话看懂
08 核心能力
09 功能示意
10 适合人群
11 项目地址
12 页码

## 留白规则

不同信息模块之间必须存在明显留白。
留白本身属于视觉设计的一部分。
标题区域留白最大。

模块内部采用：
紧凑但不拥挤的间距。

模块之间采用：
明显大于内部间距的距离。

形成视觉节奏。

## 边框与卡片

卡片：主色调作为背景

边框：1px左右细线

可采用：
与主色调相近颜色的边框。

圆角：
中等圆角。

卡片不要产生厚重阴影。

可使用非常轻微的：
外发光、内发光、玻璃高光。

## 细节设计

允许加入：
细分割线
小型圆点
状态灯
排名徽章
页码
发布日期
期数
栏目名
数据来源
项目分类
Star / Download / Growth等指标

这些细节用于建立：
“真实媒体出版物”的感觉。

## 视觉焦点

每张图片最多3个主要视觉焦点。

第一视觉焦点：
标题 / 项目名称。

第二视觉焦点：
核心结论 / 主视觉。

第三视觉焦点：
主要数据 / 功能结构。

其他元素降低视觉权重。

避免所有区域一起发光。

## 文字处理原则

优先保证中文可读性。

文字必须：
正确、完整、自然、没有乱码。

不要为了视觉效果：
随意省略文字、
生成伪文字、
生成随机英文。

所有标题应具有真实语义。

专有名词或项目名称都使用英文表达。
中文与英文混排时保持自然。

## 视觉一致性

如果生成一组系列海报：

必须保持：

相同背景
相同字体体系
相同颜色系统
相同卡片风格
相同边框
相同圆角
相同标题位置
相同品牌位置
相同页码系统
相同图标语言

允许变化：

项目Logo
主视觉
标题
数据
内容结构中的具体信息。

目标：

任何单张图片拿出来，
都能明显看出属于同一个视觉系列。

## 禁止事项

禁止：

大面积廉价渐变背景。

禁止：
过多霓虹灯。

禁止：
赛博朋克城市元素。

禁止：
复杂电路背景。

禁止：
粒子效果铺满画面。

禁止：
大量无意义光效。

禁止：
过多3D元素。

禁止：
卡通插画风。

禁止：
传统企业PPT风。

禁止：
电商促销风。

禁止：
文字拥挤。

禁止：
超小字号。

禁止：
随机乱码。

禁止：
不同模块使用完全不同设计语言。

禁止：
大量无意义装饰元素。

## 最终视觉要求

最终作品应给人这样的第一印象：

“这是一个专业AI科技媒体制作的内容卡片。”

而不是：

“这是AI随便生成的一张海报。”

视觉品质应接近：

高端AI SaaS产品官网
+
专业科技媒体
+
数据Dashboard
+
现代Editorial Design

画面需要：
高级、
统一、
精准、
清晰、
可信、
可阅读、
可持续系列化生产。
