# AutoPosting 0.4.10

## 变更

- 设置 → 模型页按三个入口分开保存：文章 / 翻译 / 对话各自「提供方下拉 + 模型下拉」。
- 已保存提供方仍列在下方。点开后用模型下拉选择，再「一键配置全部入口」。
- 模型一律用 `<select>` 列表，不再把上百个模型铺成行或勾选墙。
- 卡片和行距加大，减少拥挤。
- 应用版本 `0.4.10`。

## 边界

- 已有接口和模型目录不删除。获取可用模型会把目录写入该提供方，供下拉使用。
- 账号凭据逻辑未改。
