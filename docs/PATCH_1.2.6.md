# AutoPosting 1.2.6

## 变更

- 移除文本框下方低频对话 UI，并从设置页移除对应“对话模型”配置；保留后端兼容能力，避免旧配置或请求失效。
- 在“热点候选”文章正文加入“相关检索”：用户选中关键词或句子后，由文章模型结合选中段落及上下各一段生成检索词，再复用新闻搜索能力。
- 增加“新闻补充”侧栏。相关报道去重并限制数量后展示在侧栏，和“收藏”抽屉互斥展开。
- 热点候选文章生成期间切换栏目时保存文章会话；返回热点候选后恢复正文、标题、草稿和编辑状态，并丢弃过期生成响应。
- 修复 Skill 查找器同词结果不稳定：根因为空结果、限流/超时哨兵和错误快照被缓存，且快照为全局单槽位、查询未隔离、缓存对象可被调用方原地修改。现在按规范化查询隔离快照，识别限流/超时状态，错误/取消/降级结果不复用，并对缓存读写做深拷贝。

## 边界

- 相关检索只接受当前数据库草稿中的真实选区，浏览器 UTF-16 offset 在后端转换校验；上下文最多为选中段落及其相邻各一段，检索词必须是有限长度的 JSON 字符串。
- 新闻补充结果为当前页面会话数据，不写入收藏；搜索或模型失败时返回稳定错误码，不泄露上游异常文本。
- Skill 查找器仍受既有网络调用预算、质量门槛和最多 16 个 skill 限制；查询大小写保持原有搜索语义。
